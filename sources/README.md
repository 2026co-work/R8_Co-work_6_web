## 座標の対応

`timetable-standalone.html` の `SOURCE_CELLS` は `[開始行, 終了行, 開始列, 終了列, 原本文字列]` の配列です。行・列とも0始まりで、終了位置を含みます。

ポータル画面では `timetable-data.js` に同じデータ・合成ロジックを持ち、`app.js` から読み込みます。単独ページとのデータ一致はテストで確認しています。データ修正時は両方を更新してください。

列は月1限=0、月4限=3、火1限=4、…、金4限=19です。原本の縦結合は複数の対象行に展開し、横結合は1つの授業の `duration` に変換します。3年の通常課程・留学生、4・5年のED/EJも、元の縦の罫線区分に従って分離します。

1・2年の専門科目は二重枠をもとに判別しました。1年は月1〜4限・水3限、2年は月3限・火1〜4限・金3〜4限です。それ以外はクラス対象です。たとえば「1年M・2組」には、Mの専門科目と2組の一般科目を合わせます。

音楽・美術は縦結合された選択科目なので、選択した科目だけ表示します。原本の授業名の末尾にある「-2」などは保持しています。記載のない教室、備考、休講・振替は推測して追加していません。

## 確認方法と限界

PDF内の罫線とセル矩形を使って文字を取得しました。本文科領域の記入セルは291個。領域全体から抽出した文字と、各セルから抽出した文字を空白を除いて比較し、3,401文字が過不足なく含まれることを確認しました。この比較だけで曜日や対象の正しさを保証するものではないため、原本の画像との照合と以下のテストも行っています。

- 全124通りの学年・学科・クラス・留学生区分・芸術選択を生成し、時限範囲と重複を確認。
- 二重枠の一般／専門科目の独立した抽出を確認。
- 共通科目の縦結合と実験の横結合を区別することを確認。
- 4EJの月1限・金4限、4EDの実験、3年留学生の日本語などを原本の位置と照合。
- 出典セルと生成した授業の対応、および授業IDの一意性を確認。

これは9月24日版の基本時間割です。最新の休講・教室変更や各学生の選択科目の履修可否は、別途学校の案内で確認してください。Web画面の操作・実ブラウザーでの目視確認はこの転記検証には含みません。

## 2026年10月8日の画像照合・補正

ユーザー提供の拡大画像（1〜2年、3〜4年、5年の3枚）と照合しました。4M・金曜2限「電気電子工学Ⅰ」の担当欄は画像の `[共通]岸本` に合わせて補正しています。保存PDFは変更していません。上記の3,401文字の比較結果は補正前のPDF抽出時点の記録であり、画像補正後のデータとの完全一致を示すものではありません。

留学生の選択は全学年で受け付けますが、画像で専用の行があるのは3年です。それ以外の学年の専用時間割は推測せず、共通時間割として明示します。4・5年E学科のED／EJは、情報コース（EJ）・電気電子コース（ED）の正式名称付きで表示します。

選択変更後に古い表が残る問題を防ぐため、自動再描画とコース未選択時のクリア処理を追加し、DOMの代替を使ったイベントテストで確認しています。実ブラウザーの目視検証とは別の検証です。
