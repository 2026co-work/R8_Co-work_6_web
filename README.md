# Campus — ホームと時間割

えんじ色のサイドバーを使ったキャンパスポータルです。画面は「ホーム」「時間割」の2つです。ホームには「現在開発中」と時間割へのリンクを表示します。教室予約・空き教室・時間割変更・お知らせのデモ機能は削除しました。

## 起動

初回は `npm install`、以降は次のコマンドで起動します。

```sh
npm run dev
```

- ホーム：`http://127.0.0.1:5180/#home`
- 時間割：`http://127.0.0.1:5180/#timetable`

自分のPCからだけ接続できる設定です。ポート5180が使用中の場合は起動を停止します。`npm run build` で `dist/` に公開用ファイルを生成し、`npm run preview` で `http://127.0.0.1:5181` から確認できます。

## 選択条件のCookie保存

学年・学科・クラス・留学生区分・EJ／ED・芸術選択を変更すると、`campus-student-v1` Cookieに保存します。初回は1年M・1組が初期値です。次回アクセス時は保存した条件で時間割を表示します。

- 保存期間：最後に選択条件を変更してから1年間。ブラウザーの設定によって短くなる場合があります。
- 保存先：同じブラウザー・サイト内。Cookieを削除すると初期値に戻ります。
- GitHub Pagesのリポジトリ配下をPathに指定し、他のプロジェクトへの送信を抑えています。
- `SameSite=Lax` を設定し、HTTPSでは `Secure` を付与します。
- 保存値は列挙された選択肢と照合し、不正・破損した値は初期値に戻します。
- Cookieが拒否されても画面は使用できます。その場合は保存できなかった旨を表示します。

Cookie保存はポータル側の機能です。保存済みの単独版 `timetable-standalone.html` は以前の状態を保持しています。

## スマートフォンのメニュー

幅760px以下では、三本線ボタンで左側からメニューを開きます。背景・閉じるボタン・Escapeキー・メニュー項目の選択で閉じられます。開いている間は背景のスクロールと操作を止め、キーボードのフォーカスをメニュー内に保ちます。PCでは常時表示のサイドバーになります。

## 時間割

本科1〜5年の実時間割を収録しています。データの出典と補正内容は [sources/README.md](sources/README.md) に記録しています。

- 1・2年：クラスの一般科目と、学科の専門科目を合成。
- 3年：通常課程と留学生の行を切り替え。
- 4・5年E学科：情報コース（EJ）／電気電子コース（ED）を必須選択。
- 1年：音楽／美術の選択に対応。
- 留学生専用行のない学年は共通時間割を表示。
- 曜日を横、時限を縦に並べ、連続授業はセルを結合。スマートフォンでは表を横スクロール。

基本時間割の表示であり、休講・振替・最新の教室変更は自動取得しません。

## ファイルと検証

時間割の下にある「保存形式」でPDF／PNGを選び、「時間割をダウンロード」を押すと保存できます。PDFはA4横1ページ、PNGは横幅2,200pxの画像です。メニューや入力欄を除き、選択中の学年・学科・コース、時間割全体、出典を含めます。スマートフォンでもスクロールで隠れた列を含めて出力します。

PDFは日本語の表示を保つため画像を埋め込む方式で、文字の検索・選択はできません。処理はブラウザー内で行い、時間割を外部サービスへ送信しません。初回は出力ライブラリを読み込みます。ブラウザーによってはファイルを開いたあとに保存操作が必要です。

- `index.html`：ポータルの入口
- `app.js`：画面、Cookie保存、メニュー操作
- `styles.css`：共通デザイン・レスポンシブ表示
- `timetable-data.js`：実データと合成ロジック
- `timetable-export.js`：PNG生成・A4横PDFへの配置・ダウンロード
- `timetable-standalone.html`：保存済みの単独版
- `portal.html`：同じポータルへの別入口

```sh
npm test
npm run build
```

時間割の全124通りの選択に加え、Cookieの保存・再訪時の復元・不正値・保存拒否、メニューの開閉・フォーカス、削除済みルートの扱いを検証しています。メニュー操作テストはDOMの代替を使用しており、実ブラウザーの目視検証とは別です。
